# Getting started
{: .fs-9 }

On this page you will learn the first basic steps to get an understanding of how this application works
What you will learn:
1. How to create a new document
2. Insert a text element into a cell and edit the text
3. Assign a course and set up a schedule 
4. Save the document

### 1. Make a new document
On application startup you will see the start window. Click on **New Sheet** and an editor with a blank table will open.

![](assets/images/getting_started_1.png)

### 2. Adjusting the header size
You start off with a 2x2 grid. Let's make the columns wider by clicking and dragging to the right or left in the header section on the right end of a column.

![](assets/images/getting_started_3.gif)

{: .note }
Add more rows to the end by simply pressing Ctrl + R or columns using Ctrl + T.

### 3. Insert text into a cell
Click on the cell to activate cell edit mode. In the tool bar click on the  button and select text from the menu to insert a new empty text element. Click on the element to edit the element.

![](assets/images/getting_started_4.gif)


### 4. Editing text element and saving changes
You can now write formatted text like in a word processor using the <span style="color:blue">**toolbar**</span> at the top. When you are finished click on the <span style="color:green">**checkmark**</span> button to save the changes and close the text editor. Click another time when you have finished editing the cell as well. You can also click on a free space in the table area or press Return (Ctrl + Return for the text editor) to confirm changes. You can discard the changes by pressing Escape or clicking <span style="color:red">**X**</span> in the tool bar.

![](assets/images/getting_started_5.png)

Try out the other options from the menu.


### 5. Adding a course and setting up a time schedule
Click on <span style="color:green">**+**</span> next to the <span style="color:purple">**course selection**</span> and type in a course name and the lesson duration. You can now select the newly added course in the course selection. To schedule the lesson enter a <span style="color:brown">**date and time**</span> and click on the <span style="color:red">**schedule button**</span>. The schedule is created when you save the file.

![](assets/images/getting_started_6.png)
