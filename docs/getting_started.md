# Getting started
{: .fs-9 }

A Teachart document is a table (a sheet) for planning one lesson. Each cell holds one or more elements, such as formatted text. You can link a document to a course and a date and time. Teachart then lists it as a scheduled lesson on the start window. This page walks you through creating your first sheet. On this page you will learn the first basic steps to get an understanding of how this application works

What you will learn:
- How to create a new document
- Insert a text element into a cell and edit the text
- Assign a course and set up a schedule 
- Save the document

### 1. Make a new document
On application startup you will see the start window. Click on **New Sheet** and a new sheet opens in the editor. It starts with an empty 2×2 table.

![](assets/images/getting_started_1.png)

### 2. Resize columns
Drag the right edge of a column header to make the column wider or narrower. The cursor changes to a resize arrow when you are in the right spot

![](assets/images/getting_started_3.gif)

{: .note }
Add more rows to the end by simply pressing Ctrl + R or columns using Ctrl + T.

### 3. Insert text into a cell
Click a cell to select it. This adds an empty text element to the cell. Click the element to start typing..

![](assets/images/getting_started_4.gif)


### 4. Editing text element and saving changes
You can now write formatted text like in a word processor using the <span style="color:blue">**toolbar**</span> at the top. Click the <span style="color:green">**checkmark**</span> button to confirm the text This closes the text editor. Click the checkmark again to finish editing the cell. You can also click on a free space in the table area or press Return (Ctrl + Return for the text editor) to confirm changes. You can discard the changes by pressing Escape or clicking <span style="color:red">**X**</span> in the tool bar.

![](assets/images/getting_started_5.png)

Try out the other options from the menu such as pictures or audio files.


### 5. Adding a course and setting up a time schedule
A course groups your lessons and sets the default lesson length.
1. Click <span style="color:green">**+**</span> next to the <span style="color:purple">**course selection**</span>.
2. Enter a name and a duration, then click OK.
3. Select the new course in the course selection.
4. Enter the lesson's <span style="color:brown">**date and time**</span>, then click the <span style="color:red">**schedule button**</span>.
The schedule is created when you save the file.

![](assets/images/getting_started_6.png)

You now know the basics: a sheet is a table of cells, cells contain elements, and a sheet can be linked to a course and scheduled. Explore the rest of the docs to learn about other element types and features.
