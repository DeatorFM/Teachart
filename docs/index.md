# Teachart User Guide
{: .fs-9 }

With Teachart you can create structured plans for you lesson or presentation in a spreadsheet-like table. A normal spreadsheet program is used to organise and calculate data but a Teachart "spreadsheet" is not capable to do this. Instead you can structure your information in a table that lets you display not only text but also images and audio files. You can also selectively display these information on a second screen for example a project during a presentation. 

Because this application was created for teachers to plan their lessons you can also organise youre courses and students in a data base and moreover link your file to a schedule.

Since you might not be familiar with this kind of application browse through the docs to learn about all the different possibilities to make a structured plan.

{: .note }
Click on "Getting started" to get rough instructions on how to create you first document and to get familiar with the table controls.
